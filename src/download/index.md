# 下载安装

Wing Shot 是一款基于 Snow Shot 二次开发的截图工具，旨在提供简单、高效的截图与内容处理体验。

## 下载方式

Wing Shot 目前支持 Windows 和 macOS，具体可用安装包以 GitHub Releases 页面为准。

请前往 Wing Shot 发布页面，根据版本说明选择适合系统与架构的安装包：

- [下载最新版本](https://github.com/Anfioo/WingShot/releases/latest)
- [查看全部 GitHub Releases](https://github.com/Anfioo/WingShot/releases)

## 安装方式

### Windows

#### 安装包

运行安装包后依照程序指引安装即可。

#### 绿色版

绿色版使用压缩包打包了程序，使用压缩软件解压后直接运行即可。

*Windows 10 的部分旧版本可能无法直接通过绿色版直接运行，建议先通过安装包完成依赖的安装后再使用绿色版*

### macOS

#### 安装包

打开安装包后，将 Wing Shot 的图标拖入到显示出的文件夹中。

![MacOS 安装示例](/docs-imgs/macos-install.webp)
